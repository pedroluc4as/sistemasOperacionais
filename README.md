## 🚀 Sobre a Disciplina

Este repositório documenta a exploração do núcleo do computador. Os projetos aqui desenvolvidos têm como foco entender na prática como o sistema operacional gerencia os recursos de hardware, lidando com execução paralela, alocação e escalonamento. É a ponte direta entre o software e a API do sistema.

### 🎯 Tópicos e Práticas Abordadas
* **Concorrência e Multithreading:** Divisão de cargas de trabalho utilizando threads para processamento paralelo.
* **Gerenciamento de Processos:** Criação, execução e encerramento de processos no nível do SO.
* **Sincronização:** Tratamento de condições de corrida e acesso seguro a variáveis globais (Mutexes e Semáforos).
* **Gerenciamento de Memória:** Estratégias de alocação e paginação.

---

## ⚙️ Tecnologias e Ambiente
* **Linguagem C:** Utilizada para garantir controle total sobre a memória e acesso direto às chamadas de sistema (System Calls).
* **POSIX Threads (pthreads):** Biblioteca padrão para manipulação de concorrência e threads.
* **GCC (GNU Compiler Collection):** Compilador utilizado para as rotinas em C.
* **Linux:** Ambiente principal de execução e testes.
